ค่าเสียโอกาส (Opportunity Cost)

มูลค่าของทางเลือกที่ดีที่สุดที่ต้องสละไป เมื่อเลือกใช้ทรัพยากรทางหนึ่ง

  • เป็น “ต้นทุนที่แท้จริง” แม้ไม่ได้จ่ายเงิน
  • นับแค่ทางเลือกที่ดีที่สุดที่สละไป ไม่ใช่ทุกทางรวมกัน

มีห้องว่าง 1 ห้อง เปิดโซนกาแฟเองได้กำไร 10,000 หรือให้ร้านสะดวกซื้อเช่า 15,000/เดือน เจ้าของเลือกเปิดกาแฟ

ค่าเสียโอกาส = 15,000 บาท (ค่าเช่าที่ไม่ได้)

วันหยุด A เลือกได้ 3 ทาง: งานพิเศษได้ 2,000 · เที่ยวต่างจังหวัดเสีย 1,000 · ดูหนังที่บ้านฟรี A เลือกไปเที่ยว

ค่าเสียโอกาส = ค่าจ้าง 2,000 บาท

ต้นทุนรวมของการไปเที่ยว = จ่ายจริง 1,000 + ค่าจ้างที่เสียไป 2,000 = 3,000

ข้อ 1 · ต้นทุน

ต้นทุนการผลิตระยะสั้น

  • TFC (คงที่) ไม่เปลี่ยนตามปริมาณผลิต เช่น ค่าเช่าโรงงาน เครื่องจักร
  • TVC (ผันแปร) เปลี่ยนตามปริมาณผลิต เช่น วัตถุดิบ แรงงานรายชิ้น
  • MC ต้นทุนที่เพิ่มขึ้นเมื่อผลิตเพิ่ม 1 หน่วย

สไลด์เขียน MC = ΔTFC/ΔQ ที่ถูกคือ ΔTC/ΔQ (หรือ ΔTVC/ΔQ) เพราะ TFC ไม่เปลี่ยนตาม Q

ตัวสูตรตัวอย่าง Q = 100
TC\(TFC + TVC\)5,000 + 3,000 = 8,000
ATC\(TC/Q = AFC + AVC\)8,000 / 100 = 80
AFC\(TFC/Q\)5,000 / 100 = 50
AVC\(TVC/Q\)3,000 / 100 = 30
MC\(\Delta TC/\Delta Q\)TC 8,000 → 8,070 เมื่อ Q 100 → 101 = 70

ข้อ 1 · ต้นทุน

เส้นต้นทุนระยะสั้น

  • MC < AC → AC ลดลง
  • MC > AC → AC เพิ่มขึ้น
  • MC ตัด AVC และ AC ที่จุดต่ำสุด
  • AC อยู่เหนือ AVC เสมอ ระยะห่างคือ AFC ซึ่งแคบลงเรื่อยๆ
  • AFC ลดลงตลอด เพราะต้นทุนคงที่ถูกเฉลี่ยไปในจำนวนหน่วยที่มากขึ้น
  • AC, AVC, MC เป็นรูปตัว U เพราะกฎผลได้ลดน้อยถอยลง

ข้อ 1 · GDP

วัด GDP ได้ 3 วิธี

วิธีคิดจาก
ผลผลิตมูลค่าเพิ่ม เช่น ขายข้าวสุก 100 − ข้าวสาร 40 = 60
รายได้ค่าจ้าง + ดอกเบี้ย + ค่าเช่า + กำไร
รายจ่ายC + I + G + (X − M)
$$Y = C + I + G + (X - M)$$

C บริโภคเอกชน · I ลงทุนเอกชน · G รายจ่ายรัฐ · X ส่งออก · M นำเข้า · (X − M) ดุลการค้า

C = 5,000 · I = 3,000 · G = 2,000 · X = 1,500 · M = 2,500 (ล้านบาท)

5,000 + 3,000 + 2,000 + (1,500 − 2,500)

GDP = 9,000 ล้านบาท

เฉลยในสไลด์เขียน 8,000 แต่บวกจริงได้ 9,000

  • M > X → ขาดดุลการค้า → GDP ลดลง
  • X > M → เกินดุลการค้า → GDP เพิ่มขึ้น

ข้อ 1 · GDP

ส่วนประกอบของรายจ่ายรวม

$$\begin{aligned} C &= C_0 + MPC\cdot Y_d \qquad Y_d = Y - T \\ I &= I_0 - b\,r \\ G &= G_0 \\ X &= X_0 \\ M &= M_0 + m\,Y \end{aligned}$$
  • MPC = ΔC / ΔYd อยู่ระหว่าง 0–1 · MPC + MPS = 1
  • G, X ไม่ขึ้นกับรายได้ในประเทศ
  • m (MPM) สูง → รายได้รั่วไปกับการนำเข้า → ตัวทวีคูณลดลง
  • ดอกเบี้ยขึ้น → I ลด · บาทอ่อน → X เพิ่ม

รายได้ 10,000 → 12,000 · บริโภค 8,000 → 9,600

MPC = 1,600 / 2,000 = 0.8 · MPS = 0.2

I₀ = 500 · b = 20 · r = 5

I = 500 − 20(5) = 400

รายได้ 1,000 → 1,500 · นำเข้า 300 → 400

MPM = 100 / 500 = 0.2

รายได้ดุลยภาพ เสริม

$$Y = \frac{C_0 - MPC\cdot T + I + G + X - M_0}{1 - MPC + m}$$

$$\begin{aligned} \text{Nominal} &= \textstyle\sum Q_{\text{ปีนั้น}} \times P_{\text{ปีนั้น}} \\ \text{Real} &= \textstyle\sum Q_{\text{ปีนั้น}} \times P_{\text{ปีฐาน}} \\ \text{Deflator} &= \frac{\text{Nominal}}{\text{Real}} \times 100 \\ \text{Growth} &= \frac{\text{Real}_t - \text{Real}_{t-1}}{\text{Real}_{t-1}} \times 100 \end{aligned}$$

ข้อ 2 · 4 คะแนน

Lagrange: หาค่าเหมาะสุดภายใต้ข้อจำกัด

1) Profit Maximization

$$\begin{aligned} &\max_{x,y}\ \pi(x,y) \quad \text{s.t.}\ g(x,y) = \bar R \\ &\mathcal{L} = \pi(x,y) + \lambda\,[\bar R - g(x,y)] \\ &\frac{\partial\mathcal{L}}{\partial x} = \frac{\partial\pi}{\partial x} - \lambda\frac{\partial g}{\partial x} = 0 \\ &\frac{\partial\mathcal{L}}{\partial y} = \frac{\partial\pi}{\partial y} - \lambda\frac{\partial g}{\partial y} = 0 \\ &\frac{\partial\mathcal{L}}{\partial\lambda} = \bar R - g(x,y) = 0 \end{aligned}$$

2) Cost Minimization

$$\begin{aligned} &\min_{L,K}\ C = wL + rK \quad \text{s.t.}\ f(L,K) = \bar Q \\ &\mathcal{L} = wL + rK + \lambda\,[\bar Q - f(L,K)] \\ &\frac{\partial\mathcal{L}}{\partial L} = w - \lambda MP_L = 0 \\ &\frac{\partial\mathcal{L}}{\partial K} = r - \lambda MP_K = 0 \\ &\frac{\partial\mathcal{L}}{\partial\lambda} = \bar Q - f(L,K) = 0 \end{aligned}$$ $$\boxed{\dfrac{MP_L}{MP_K} = \dfrac{w}{r}}$$

ข้อ 2 · 4 คะแนน

ขั้นตอนทำโจทย์ Lagrange

  1. เขียนเป้าหมาย (max π หรือ min C) และข้อจำกัด
  2. ตั้ง ℒ = เป้าหมาย + λ [ค่าคงที่ − ข้อจำกัด]
  3. ดิฟ ℒ เทียบทุกตัวแปรและ λ แล้วให้ = 0
  4. หารสมการ FOC 2 สมการแรก เพื่อตัด λ ออก
  5. แทนลงข้อจำกัด → ได้ x*, y* → ย้อนหา λ*
λ* หมายถึงอะไร
  • Cost min: λ* = MC ต้นทุนที่เพิ่มถ้าผลิตเพิ่ม 1 หน่วย
  • Profit max: λ* กำไรที่เพิ่มถ้าข้อจำกัดคลายออก 1 หน่วย (shadow price)

ทริกดิฟ Cobb-Douglas

$$Q = A L^{a} K^{b} \;\Rightarrow\; MP_L = \frac{aQ}{L},\ \ MP_K = \frac{bQ}{K}$$ $$\frac{MP_L}{MP_K} = \frac{a}{b}\cdot\frac{K}{L}$$

ข้อ 2 · ตัวอย่าง

ตัวอย่าง A: ต้นทุนต่ำสุด

min \(C = 4L + 16K\)  s.t.  \(L^{0.5}K^{0.5} = 20\)

ตั้ง ℒ และ FOC

$$\begin{aligned} \mathcal{L} &= 4L + 16K + \lambda\,[20 - L^{0.5}K^{0.5}] \\ \partial L:&\quad 4 - 0.5\lambda L^{-0.5}K^{0.5} = 0 \\ \partial K:&\quad 16 - 0.5\lambda L^{0.5}K^{-0.5} = 0 \\ \partial\lambda:&\quad L^{0.5}K^{0.5} = 20 \end{aligned}$$

หาร 2 สมการแรก

$$\frac{4}{16} = \frac{K}{L} \;\Rightarrow\; K = \frac{L}{4}$$

แทนลงข้อจำกัด

$$\sqrt{L\cdot\tfrac{L}{4}} = \frac{L}{2} = 20 \;\Rightarrow\; L = 40,\ K = 10$$

L* = 40 · K* = 10

C* = 4(40) + 16(10) = 320

\(4 = 0.5\lambda\sqrt{10/40} = 0.25\lambda\) → λ* = 16 (ผลิตเพิ่ม 1 หน่วย ต้นทุนเพิ่ม ≈ 16)

ตัวอย่าง B: กำไรสูงสุด

max \(\pi = 60x + 40y - x^2 - y^2\)  s.t.  \(x + y = 30\)

$$\begin{aligned} \mathcal{L} &= 60x + 40y - x^2 - y^2 + \lambda\,[30 - x - y] \\ \partial x:&\quad 60 - 2x - \lambda = 0 \\ \partial y:&\quad 40 - 2y - \lambda = 0 \\ \partial\lambda:&\quad x + y = 30 \end{aligned}$$

ลบสมการแรกด้วยสมการที่สอง: \(20 - 2x + 2y = 0 \Rightarrow x - y = 10\)

x* = 20 · y* = 10 · λ* = 60 − 40 = 20

π* = 1,200 + 400 − 400 − 100 = 1,100

ถ้ากำลังผลิตเพิ่มอีก 1 หน่วย กำไรเพิ่ม ≈ 20

อีกแบบ: ผลผลิตสูงสุดภายใต้งบ

max \(Q = L^{0.5}K^{0.5}\)  s.t.  \(4L + 16K = 320\)

$$\mathcal{L} = L^{0.5}K^{0.5} + \lambda\,[320 - 4L - 16K]$$

ได้เงื่อนไขเดิม \(\dfrac{MP_L}{MP_K} = \dfrac{w}{r}\) → K = L/4 → 4L + 4L = 320

L = 40 · K = 10 · Q = 20
คำตอบเดียวกับตัวอย่าง A (เป็นปัญหาคู่กัน)

Isoquant และ MRTS

  • Isoquant = ส่วนผสม L และ K ที่ให้ผลผลิตเท่ากัน
  • เส้นไกลจุดกำเนิดกว่า = ผลผลิตมากกว่า
  • โค้งเว้าเข้าหาจุดกำเนิด เพราะปัจจัยทดแทนกันได้
$$MRTS_{LK} = -\frac{\Delta K}{\Delta L} = \frac{MP_L}{MP_K}$$

  • จุดตัดแกน: L = C/w · K = C/r
  • C เพิ่ม → เส้นเลื่อนออกขนาน
  • w หรือ r เปลี่ยน → เส้นหมุน

จุดเหมาะสม = Isocost สัมผัส Isoquant

$$\frac{MP_L}{MP_K} = \frac{w}{r} \iff \frac{MP_L}{w} = \frac{MP_K}{r}$$
  • \(MP_L/w > MP_K/r\) → ใช้ L เพิ่ม ลด K
  • \(MP_L/w < MP_K/r\) → ใช้ K เพิ่ม ลด L

Expansion Path และตัวอย่าง

เส้นลากผ่านจุดสัมผัสทุกระดับต้นทุน (X, Y, Z) = วิธีขยายการผลิตอย่างมีประสิทธิภาพ

\(Q = L^{0.5}K^{0.5}\) · w = 20 · r = 5 · งบ C = 400 ควรใช้ L และ K เท่าไร

$$\begin{aligned} \frac{MP_L}{MP_K} = \frac{K}{L} &= \frac{w}{r} = \frac{20}{5} = 4 \\ K &= 4L \\ 20L + 5(4L) &= 40L = 400 \end{aligned}$$

L = 10 · K = 40 · Q = √400 = 20

ค่าแรงแพงกว่าค่าทุน จึงควรใช้ทุนมากกว่าแรงงาน

ต้นทุนทางสังคมและผลกระทบภายนอก

$$\text{Social Cost} = \text{Private Cost} + \text{External Cost}$$
  • Private Cost = ผู้ผลิตหรือผู้บริโภคจ่ายเอง เช่น วัตถุดิบ ค่าแรง ค่าขนส่ง
  • External Cost = ตกกับคนอื่นโดยไม่มีใครชดเชย เช่น มลพิษ ความแออัด ปัญหาสุขภาพ
กรณีผลที่เกิด
Private < Social
ผลกระทบภายนอกเชิงลบ · มลพิษ รถติด		ผลิต/บริโภคมากเกินไป
Private > Social
ผลกระทบภายนอกเชิงบวก · การศึกษา วัคซีน		สังคมได้ประโยชน์มากกว่าที่ผู้จ่ายรู้สึก → มักผลิตน้อยเกินไป

โรงงานเหล็กมีต้นทุนเอกชน 1,000,000 บาท/เดือน ควันและฝุ่นทำให้ชุมชนเสียค่ารักษาสุขภาพเพิ่ม 300,000 บาท/เดือน

Social Cost = 1,000,000 + 300,000 = 1,300,000 บาท

โรงงานคิดแค่ 1,000,000 → ผลิตมากเกินไป เพราะไม่ต้องรับผิดชอบผลกระทบต่อคนอื่น → Negative Externality

ตอบให้ครบ 3 ส่วน
  1. คำนวณ Social = Private + External
  2. บอกว่า Private < Social หรือ > Social
  3. สรุปว่าผลิตมากหรือน้อยเกินไป และเป็นผลกระทบเชิงลบหรือเชิงบวก
