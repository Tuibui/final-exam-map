ต้นทุนชัดแจ้ง · ต้นทุนแอบแฝง · กำไร

$$\text{Economic Cost} = \text{Explicit} + \text{Implicit}$$
  • Economic Costต้นทุนทางเศรษฐศาสตร์ (ต้นทุนทั้งหมดที่แท้จริง)
  • Explicitต้นทุนชัดแจ้ง = จ่ายเงินจริง ลงบัญชีได้ เช่น วัตถุดิบ ค่าแรง ค่าเช่า ค่าน้ำไฟ
  • Implicitต้นทุนแอบแฝง = ไม่ได้จ่ายเงิน แต่เสียโอกาส เช่น เงินเดือนที่ลาออกมา บ้านตัวเองที่ไม่ได้ปล่อยเช่า

กำไร เสริม

$$\begin{aligned}\text{กำไรทางบัญชี} &= TR - \text{Explicit} \\ \text{กำไรทางเศรษฐศาสตร์} &= TR - (\text{Explicit} + \text{Implicit})\end{aligned}$$

$$\begin{aligned} C &= C_0 + MPC\cdot Y_d \\ Y_d &= Y - T \\ I &= I_0 - b\,r \\ G &= G_0 \\ X &= X_0 \\ M &= M_0 + m\,Y \end{aligned}$$
  • MPC อยู่ระหว่าง 0–1 และ MPC + MPS = 1
  • ดอกเบี้ยขึ้น → I ลด · บาทอ่อน → X เพิ่ม
  • m สูง → รายได้รั่วไปกับการนำเข้า → ตัวทวีคูณลดลง
  • Cการบริโภคทั้งหมด
  • \(C_0\)การบริโภคอัตโนมัติ: ต้องบริโภคแม้รายได้ = 0
  • MPCความโน้มเอียงบริโภคส่วนเพิ่ม: รายได้เพิ่ม 1 บาท บริโภคเพิ่มกี่บาท (= ΔC/ΔYd)
  • MPSความโน้มเอียงออมส่วนเพิ่ม = 1 − MPC
  • \(Y_d\)รายได้ที่ใช้จ่ายได้ (หลังหักภาษี)
  • Yรายได้ประชาชาติรวม
  • Tภาษี
  • Iการลงทุน
  • \(I_0\)การลงทุนอัตโนมัติ (ไม่ขึ้นกับดอกเบี้ย)
  • bความไวของการลงทุนต่อดอกเบี้ย เช่น b = 20 → ดอกเบี้ยขึ้น 1 หน่วย ลงทุนลด 20
  • rอัตราดอกเบี้ย
  • \(G_0\)รายจ่ายรัฐที่กำหนดไว้ล่วงหน้า (ไม่ขึ้นกับรายได้)
  • \(X_0\)มูลค่าส่งออก ขึ้นกับความต้องการของต่างประเทศ
  • Mการนำเข้า
  • \(M_0\)การนำเข้าอัตโนมัติ
  • mความโน้มเอียงนำเข้าส่วนเพิ่ม (MPM): รายได้เพิ่ม 1 บาท นำเข้าเพิ่มกี่บาท (= ΔM/ΔY)

1. Multiplier Effect

$$\Delta Y = \frac{1}{1 - MPC}\,\Delta I$$
  • ΔYรายได้ประชาชาติที่เพิ่มขึ้น
  • ΔIการลงทุนที่เพิ่มขึ้น
  • MPCความโน้มเอียงบริโภคส่วนเพิ่ม
  • \(\frac{1}{1-MPC}\)ตัวทวีคูณ: ลงทุน 1 บาท รายได้เพิ่มกี่บาท

เงินหมุนหลายรอบ: จ้างคนงาน → คนงานนำเงินไปใช้ → ร้านค้าขายได้ → ผลิตและจ้างงานเพิ่ม

MPC = 0.8 · ลงทุนเพิ่ม 100

ตัวคูณ = 1/(1 − 0.8) = 5 → Y เพิ่ม 500

2. Crowding-in (ผลบวก)
รัฐลงทุนในโครงการเพิ่มผลิตภาพ → เอกชนลงทุนตาม
EEC: รัฐสร้างรถไฟเชื่อม 3 สนามบิน ท่าเรือแหลมฉบัง → เอกชนสร้างนิคม โรงงาน โรงแรม

Lagrange 1: กำไรสูงสุดภายใต้ข้อจำกัด

$$\begin{aligned} &\max_{x,y}\ \pi(x,y) \quad \text{s.t.}\ g(x,y) = \bar R \\[4pt] &\mathcal{L} = \pi(x,y) + \lambda\,[\bar R - g(x,y)] \\[4pt] &\frac{\partial\mathcal{L}}{\partial x} = \frac{\partial\pi}{\partial x} - \lambda\frac{\partial g}{\partial x} = 0 \\ &\frac{\partial\mathcal{L}}{\partial y} = \frac{\partial\pi}{\partial y} - \lambda\frac{\partial g}{\partial y} = 0 \\ &\frac{\partial\mathcal{L}}{\partial\lambda} = \bar R - g(x,y) = 0 \end{aligned}$$
  • π(x, y)ฟังก์ชันกำไร (สิ่งที่อยากให้มากที่สุด)
  • x, yตัวแปรที่เลือกได้ เช่น ปริมาณสินค้า 2 ชนิดที่จะผลิต
  • g(x, y)ฟังก์ชันข้อจำกัด เช่น ทรัพยากรหรือกำลังผลิตที่ใช้
  • \(\bar R\)ค่าคงที่ของข้อจำกัด เช่น ทรัพยากร/กำลังผลิตที่มีทั้งหมด
  • s.t.subject to = “ภายใต้เงื่อนไข”
  • ℒฟังก์ชันลากรานจ์ (เป้าหมาย + λ × ข้อจำกัด)
  • λตัวคูณลากรานจ์: กำไรที่เพิ่มขึ้นถ้าข้อจำกัด \(\bar R\) เพิ่ม 1 หน่วย (shadow price)
  • ∂ℒ/∂xอนุพันธ์ย่อย: ดิฟ ℒ เทียบ x โดยถือตัวอื่นเป็นค่าคงที่
  • x*, y*, λ*คำตอบที่ได้จากการแก้ระบบสมการ FOC
  • FOCFirst-Order Conditions: เงื่อนไขอนุพันธ์ = 0

Lagrange 2: ต้นทุนต่ำสุดภายใต้ข้อจำกัด

$$\begin{aligned} &\min_{L,K}\ C = wL + rK \quad \text{s.t.}\ f(L,K) = \bar Q \\[4pt] &\mathcal{L} = wL + rK + \lambda\,[\bar Q - f(L,K)] \\[4pt] &\frac{\partial\mathcal{L}}{\partial L} = w - \lambda MP_L = 0 \\ &\frac{\partial\mathcal{L}}{\partial K} = r - \lambda MP_K = 0 \\ &\frac{\partial\mathcal{L}}{\partial\lambda} = \bar Q - f(L,K) = 0 \end{aligned}$$ $$\boxed{\dfrac{MP_L}{MP_K} = \dfrac{w}{r}}$$
  • Cต้นทุนรวม (สิ่งที่อยากให้น้อยที่สุด)
  • Lปริมาณแรงงานที่ใช้
  • Kปริมาณทุนที่ใช้
  • wค่าจ้างแรงงานต่อหน่วย (wage)
  • rค่าเช่าทุนต่อหน่วย (rent) · ในบทนี้ r ไม่ใช่ดอกเบี้ย
  • f(L, K)ฟังก์ชันการผลิต
  • \(\bar Q\)ปริมาณผลผลิตที่ต้องผลิตให้ได้
  • \(MP_L\)ผลผลิตส่วนเพิ่มของแรงงาน = ∂f/∂L
  • \(MP_K\)ผลผลิตส่วนเพิ่มของทุน = ∂f/∂K
  • λต้นทุนที่เพิ่มขึ้นถ้าต้องผลิตเพิ่ม 1 หน่วย (= MC)
  • ผลลัพธ์ใช้ปัจจัยจน MPL/MPK เท่ากับอัตราส่วนราคา w/r

ขั้นตอนทำโจทย์ Lagrange

  1. เขียนเป้าหมาย (max π หรือ min C) และข้อจำกัด
  2. ตั้ง ℒ = เป้าหมาย + λ [ค่าคงที่ − ข้อจำกัด]
  3. ดิฟ ℒ เทียบทุกตัวแปรและ λ แล้วให้ = 0
  4. หารสมการ FOC 2 สมการแรก เพื่อตัด λ ออก
  5. แทนลงข้อจำกัด → ได้ x*, y* → ย้อนหา λ*

ทริกดิฟ Cobb-Douglas

$$Q = A L^{a} K^{b} \;\Rightarrow\; MP_L = \frac{aQ}{L},\ \ MP_K = \frac{bQ}{K}$$ $$\frac{MP_L}{MP_K} = \frac{a}{b}\cdot\frac{K}{L}$$
  • Qผลผลิต
  • Aค่าคงที่ (เทคโนโลยี)
  • aเลขชี้กำลังของ L
  • bเลขชี้กำลังของ K

เช่น Q = L0.5K0.5 → MPL/MPK = (0.5/0.5)(K/L) = K/L

ตัวอย่าง A: ต้นทุนต่ำสุด

min \(C = 4L + 16K\)  s.t.  \(L^{0.5}K^{0.5} = 20\)

  • L, Kแรงงาน, ทุน ที่ต้องหา
  • 4= w ค่าจ้างต่อหน่วย
  • 16= r ค่าเช่าทุนต่อหน่วย
  • 20= \(\bar Q\) ผลผลิตที่ต้องได้
$$\begin{aligned} \mathcal{L} &= 4L + 16K + \lambda\,[20 - L^{0.5}K^{0.5}] \\ \partial L:&\quad 4 - 0.5\lambda L^{-0.5}K^{0.5} = 0 \\ \partial K:&\quad 16 - 0.5\lambda L^{0.5}K^{-0.5} = 0 \\ \partial\lambda:&\quad L^{0.5}K^{0.5} = 20 \end{aligned}$$

หาร 2 สมการแรก

$$\frac{4}{16} = \frac{K}{L} \;\Rightarrow\; K = \frac{L}{4}$$

แทนลงข้อจำกัด

$$\sqrt{L\cdot\tfrac{L}{4}} = \frac{L}{2} = 20 \;\Rightarrow\; L = 40,\ K = 10$$

L* = 40 · K* = 10

C* = 4(40) + 16(10) = 320

\(4 = 0.5\lambda\sqrt{10/40} = 0.25\lambda\) → λ* = 16 (ผลิตเพิ่ม 1 หน่วย ต้นทุนเพิ่ม ≈ 16)

Isoquant และ MRTS

  • Isoquant (IQ) = ส่วนผสม L และ K ที่ให้ผลผลิตเท่ากัน
  • เส้นไกลจุดกำเนิดกว่า = ผลผลิตมากกว่า
  • โค้งเว้าเข้าหาจุดกำเนิด เพราะปัจจัยทดแทนกันได้
$$MRTS_{LK} = -\frac{\Delta K}{\Delta L} = \frac{MP_L}{MP_K}$$
  • \(MRTS_{LK}\)อัตราทดแทนทางเทคนิค: เพิ่ม L 1 หน่วย ลด K ได้กี่หน่วยโดยผลผลิตเท่าเดิม
  • ΔKทุนที่ลดลง
  • ΔLแรงงานที่เพิ่มขึ้น
  • \(MP_L\), \(MP_K\)ผลผลิตส่วนเพิ่มของแรงงาน, ของทุน

MRTS = ความชันของ Isoquant และลดลงเรื่อยๆ (4 → 3 → 2)

Isocost และจุดเหมาะสม

$$C = wL + rK \qquad \text{ความชัน} = -\frac{w}{r}$$
  • Cงบหรือต้นทุนรวม
  • wค่าจ้างแรงงานต่อหน่วย
  • rค่าเช่าทุนต่อหน่วย
  • L, Kแรงงาน, ทุน
  • จุดตัดแกน: L = C/w · K = C/r
  • C เพิ่ม → เส้นเลื่อนออกขนาน · w หรือ r เปลี่ยน → เส้นหมุน

จุดเหมาะสม = Isocost สัมผัส Isoquant

$$\frac{MP_L}{MP_K} = \frac{w}{r} \iff \frac{MP_L}{w} = \frac{MP_K}{r}$$
  • \(MP_L/w\)ผลผลิตที่ได้ต่อเงิน 1 บาทที่จ่ายให้แรงงาน
  • \(MP_K/r\)ผลผลิตที่ได้ต่อเงิน 1 บาทที่จ่ายให้ทุน
  • \(MP_L/w > MP_K/r\) → แรงงานคุ้มกว่า ใช้ L เพิ่ม ลด K
  • \(MP_L/w < MP_K/r\) → ทุนคุ้มกว่า ใช้ K เพิ่ม ลด L

  • Private Costต้นทุนเอกชน: ผู้ผลิตหรือผู้บริโภคจ่ายเอง เช่น วัตถุดิบ ค่าแรง ค่าขนส่ง
  • External Costต้นทุนภายนอก: ตกกับคนอื่นโดยไม่มีใครชดเชย เช่น มลพิษ ความแออัด ค่ารักษาสุขภาพ
กรณีผลที่เกิด
Private < Social
ผลกระทบภายนอกเชิงลบ · มลพิษ รถติด		ผลิต/บริโภคมากเกินไป
Private > Social
ผลกระทบภายนอกเชิงบวก · การศึกษา วัคซีน		สังคมได้ประโยชน์มากกว่าที่ผู้จ่ายรู้สึก → มักผลิตน้อยเกินไป

โรงงานเหล็กมีต้นทุนเอกชน 1,000,000 บาท/เดือน ควันและฝุ่นทำให้ชุมชนเสียค่ารักษาสุขภาพเพิ่ม 300,000 บาท/เดือน

Social Cost = 1,000,000 + 300,000 = 1,300,000 บาท

โรงงานคิดแค่ 1,000,000 → ผลิตมากเกินไป เพราะไม่ต้องรับผิดชอบผลกระทบต่อคนอื่น → Negative Externality

ตอบให้ครบ 3 ส่วน
  1. คำนวณ Social = Private + External
  2. บอกว่า Private < Social หรือ > Social
  3. สรุปว่าผลิตมากหรือน้อยเกินไป และเป็นผลกระทบเชิงลบหรือเชิงบวก

ภาพผลกระทบภายนอกเชิงลบ เสริม

  • Pราคา
  • Qปริมาณ
  • Dอุปสงค์ (ความต้องการซื้อ)
  • MPCต้นทุนส่วนเพิ่มของเอกชน (Marginal Private Cost) · ไม่ใช่ MPC การบริโภค
  • MSCต้นทุนส่วนเพิ่มทางสังคม = MPC + ต้นทุนภายนอก
  • Q ตลาดปริมาณที่ตลาดผลิตจริง (MPC ตัด D)
  • Q*ปริมาณที่เหมาะกับสังคม (MSC ตัด D)

MSC อยู่เหนือ MPC → Q* < Q ตลาด → ผลกระทบภายนอกเชิงลบทำให้ผลิตมากเกินไป

แนวแก้ ผลเสีย → เก็บภาษีเท่าต้นทุนภายนอก หรือออกกฎคุมมลพิษ · ผลดี → ให้เงินอุดหนุน เช่น วัคซีนฟรี
