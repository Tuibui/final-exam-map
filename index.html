Stress–strain diagram และ Hooke's law

ต้องเข้าใจกราฟ stress–strain ว่าแต่ละจุดเกิดอะไรขึ้น ช่วง elastic อยู่ตรงไหน plastic อยู่ตรงไหน และ fracture เกิดตรงไหน

  • ลำดับบนกราฟ: elastic deformation → yield → plastic deformation → strain hardening → necking → fracture
  • Hooke (1678): ในช่วง elastic ความเค้นแปรผันตรงกับความเครียด
  • วัสดุที่ไม่มีจุด yield ชัด เช่น cast iron, Cu, ทองเหลือง, Al ใช้ 0.2% proof stress แทน
E = σ / ε = P·l / (A·λ) [N/m² = Pa] ความชัน = rise / run

Fatigue test และ Creep test

ไม่ได้พูดถึงตอนทบทวน เพราะอาจารย์ปิดหัวข้อ testing หลัง impact ควรอ่านผ่าน ๆ ไว้

    • martensite เกิดจาก shear transformation โดยไม่ต้องให้ C แพร่
  • ช่วงวิกฤต: ต้องผ่านจาก A₁/A₃ ลงถึง 550°C ให้เร็ว
  • ต่ำกว่าประมาณ 250°C: martensite ขยายตัวมาก ต้องเย็นช้าลง ถ้าผิวกับแกนขยายไม่เท่ากันจะเกิด quench crack
  • Mass effect: ผิวกับแกนมีความแข็งต่างกัน

ออกสอบ

Tempering 焼戻し

  • ทำคู่กับ quenching เสมอ: อุ่นซ้ำแล้วปล่อยเย็นในอากาศ เพื่อลดความเค้นตกค้าง ปรับความแข็ง และคืนความเหนียว
  • ขั้นที่ 1 (80–160°C): C ตกผลึกออกจาก martensite
  • ขั้นที่ 2 (230–280°C): retained austenite เปลี่ยนเป็น lower bainite
  • ขั้นที่ 3 (>300°C): cementite ปรากฏ ได้ troostite และ sorbite
  • Troostite (~400°C): กัดกร่อนง่าย แข็งน้อยกว่า martensite แต่แข็งกว่า sorbite
  • Sorbite (~600°C): กัดกร่อนยาก แข็งน้อยกว่า martensite แต่เหนียวกว่า
หน้า 18, 21–22
ออกสอบ

Annealing 焼なまし

  • จุดประสงค์: ทำให้เหล็กอ่อนลงเพื่อกลึงหรือขึ้นรูปง่าย ทำให้เนื้อสม่ำเสมอ และลดความเค้นตกค้าง
  • Full annealing:
    • hypo-eutectoid ให้ความร้อนสูงกว่า A₃ อยู่ 20–30°C ส่วน hyper-eutectoid สูงกว่า A₁ อยู่ 30–50°C
    • เย็นช้าในเตาไม่เกิน 20°C/ชม.
    • ได้ pearlite แบบชั้นที่อ่อน
  • Low-temperature (stress relief) annealing: ลดความเค้นจากการกลึง ขึ้นรูป หรือเชื่อม โดย recrystallization ที่อุณหภูมิเกินประมาณ 450°C
  • Spheroidizing: เปลี่ยน cementite ให้เป็นทรงกลมกระจายอยู่ใน ferrite
หน้า 23–24
ออกสอบ

Normalizing 焼ならし

  • จุดประสงค์: ทำให้เกรนละเอียดและสม่ำเสมอ และลดความเค้นจากการขึ้นรูปหรือหล่อ
  • อุณหภูมิ: hypo-eutectoid สูงกว่า A₃ อยู่ 40–60°C ส่วน hyper-eutectoid สูงกว่า Acm อยู่ 40–60°C แล้วปล่อยเย็นในอากาศ
  • ทำไม hyper-eutectoid ต้องร้อนกว่าตอน quench และ anneal: เพื่อให้เป็น austenite เฟสเดียว
  • ได้ผลมากกับเหล็ก C ≤ 0.2%: เหล็กกลุ่มนี้ quench แล้วแข็งขึ้นไม่มาก
  • Standard normalizing: ปล่อยเย็นในอากาศจนถึงอุณหภูมิห้อง
  • Second-stage normalizing: ปล่อยเย็นในอากาศถึงประมาณ 550°C แล้วเย็นช้าในหลุมหรือเตา ช่วยกันรอยร้าวภายใน
